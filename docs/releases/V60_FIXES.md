# V60 changes
- New switch "الجمل المحفوظة" (Settings): phrase learning ON/OFF, like the autocorrect switch.
  ON (default, unchanged behaviour): saves typed sentences and suggests them.
  OFF: no new sentences are saved and the saved ones are not suggested (they are NOT deleted; the existing
  "مسح الجمل المحفوظة" button still does that). Single-word learning is unchanged.
Not compiled here: build in CI and test on a device.
